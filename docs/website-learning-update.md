# Website learning update

Implemented in `C:/Users/Muttaqi Ahmed/Desktop/arabicwithm`. No deployment, commit or push was performed.

1. **Memory sign-in:** Previously the server returned a standalone sign-in notice. The Memory route now mounts the existing AuthDialog automatically. Dismissing it leaves personal content and session controls inaccessible, with a Sign In action to reopen it. Password sign-in closes the dialog and refreshes Memory in place. OAuth's safe return allowlist now includes Memory and Grammar, retaining their query strings.
2. **British English:** New flow copy uses “Sign in to practise Memory/Grammar”, “Practise again”, “colours” and “Unlevelled Hans Wehr practice” (a noun). Existing technical identifiers are unchanged.
3. **Free Memory notice:** A centred, outlined notice places the information icon above the text and the full-width “Upgrade to Arabic with M” action below it. The existing daily-session backend is unchanged: free users get one new session; premium/admin remain unlimited; resuming or viewing a saved recap does not create a new session.
4. **Chapter navigation:** The footer contains equal-height All Chapters and Next Chapter links on one row. It does not display previous/next chapter titles or a previous-chapter footer link. The final chapter contains only centred All Chapters. Existing safe bottom spacing remains.
5. **Explore architecture:** AWM is the website default. Its existing ExploreFeed is retained. The tabs mount either the existing feed or ForYouFeed; both use the existing useYouTubePlayer integration. Leaving a clip destroys its player, and entering For You closes global PiP.
6. **Exact For You data:** The authenticated-cookie/public-key server client calls the existing `public.transcript_for_you_groups` RPC in project `whbxgwucsoguqzpnpzjd`. This reads the shared `youtube_transcripts` / `transcript_segments` library and existing Admin transcript group associations. The RPC requires ready, searchable Arabic Admin provenance; rejects AWM channel content, related episode records and flagged music; the website does not query Shows/Episodes for these clips.
7. **Selection and length:** Selection remains in the mobile RPC, using its seed, recent-source and excluded-segment parameters. The website accepts only complete timed segment windows lasting 10–60 seconds; it does not trim words or rewrite timings. A bounded read-time guard excludes confirmed Best of Stories closing-song couplets whose existing database theme score is zero. Rejected segment IDs remain excluded for the web session. The mobile fingerprint rule also suppresses repeated clips at 70% overlap, with at least four fingerprints. Requests have a ten-second network deadline and a bounded maximum of three selection passes when a batch is entirely unsuitable.
8. **Highlighting:** Playback follows actual player media time. Explicit absolute `start_ms` / `end_ms` word timings are honoured only when finite, ordered and inside the segment. Segment highlighting remains available independently. No word timestamps are generated.
9. **Incomplete enrichment:** Missing token data falls back to the original Arabic segment and stored English sentence. Missing glosses/POS do not exclude a useful clip. No translations or grammatical analysis are generated. If YouTube's API fails, the shared player uses a bounded native embed; automatic progression/following and external speed controls cannot operate without that API, so manual Next remains available.
10. **Settings:** Word interaction, word meanings, contextual English, playback highlighting, transcript following and conservative POS colours are persisted in localStorage. Optional settings are shown only when the current clip has supporting data. Hover uses existing word cards; tapping opens the existing definition sheet and pauses playback.
11. **Controls:** Play/pause, native supported playback rates, replay, Next and Settings form a compact row. Speed changes follow YouTube's accepted-rate event and persist between clips. Completion uses media time and a one-shot guard; the source-ended event also handles clips ending at the video's end. Watch Full Video uses the stored YouTube ID and clip start.
12. **Grammar entry:** Grammar is in the Home page's actual Quick Actions grid, alongside the existing actions. It opens Naḥw / Ṣarf choices. Signed-out visitors use the existing sign-in dialog; Grammar has no new premium gate. The bookmark/profile shortcut row remains intact.
13. **Naḥw catalogue:** Word Type, Sentence Role, Case, Phrase & Clause Roles, Governance & Iʿrāb, Build the Sentence and Revise Nahw Rules. Candidates come from the existing `nahw_candidates` RPC. The adapter preserves reviewed multi-token targets, longest non-overlapping spans, contextual explanations, fronted predicates/delayed topics, compatible noun/verb case trays and reviewed relationships. Tap/drag placements lock after a correct answer; wrong attempts preserve the choices. Governance and sentence-building use reviewed relation pairs. Sessions favour varied sources/labels or simpler reviewed structures as appropriate.
14. **Ṣarf catalogue:** Forms & Roots with 3-/4-letter filters, Context Ṣarf, Weak Verbs, Word Patterns and Ten Forms revision. Form/pattern/rule data and attested Hans Wehr fallback stems are exported from mobile; all ten forms and four quadriliteral patterns are retained. Weak identification and conjugation recall use the existing verified weak-verb data/explanations, balanced type selection and bounded Again reinforcement. Form sessions balance patterns rather than repeatedly selecting Form I.
